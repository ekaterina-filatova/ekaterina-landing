🌐 Лендинг «Екатерина Филатова — нейросети для бизнеса»
Одностраничный сайт-визитка специалиста по нейросетям: каталог услуг,блок «обо мне» и форма заявки с автоматической отправкой в Google Таблицу.

▶ Живой сайт: https://ekaterina-filatova.github.io/ekaterina-landing/

✨ Возможности
🛠 Каталог из 5 услуг с описанием, сроками и кнопками «Обсудить задачу»
📝 Форма заявки с валидацией ввода и защитой от спама (honeypot)
📊 Автоматический сбор заявок в Google Таблицу — без сервера и базы данных
📱 Адаптивная вёрстка: корректно на смартфоне, планшете и десктопе
⚡️ Весь сайт в одном файле index.html — без сборки и внешних зависимостей
🧰 Стек
HTML5 + CSS3 (адаптивная вёрстка, анимации, glassmorphism)
Vanilla JavaScript (валидация формы, плавный скролл, reveal-анимации)
Google Apps Script (приём заявок в таблицу)
Деплой: GitHub Pages
🚀 Локальный запуск
Скачайте index.html и photo.jpg в одну папку
Откройте index.html в браузере — сайт работает сразу
Форма заявок требует подключения к интернету.

📬 Как устроен приём заявок
Форма отправляет POST-запрос на Google Apps Script Web App(адрес — в константе SCRIPT_URL внутри index.html), скрипт записываетданные в Google Таблицу: дата, имя, контакт, выбранная услуга.

Чтобы подключить свою таблицу: создайте свой Apps Script Web Appс функцией doPost(e), читающей e.postData.contents, и заменитезначение SCRIPT_URL в index.html.
